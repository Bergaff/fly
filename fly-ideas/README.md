# Fly Ideas

Десктоп-программа (Windows 10+) для работы с идеями научных статей на модели мозга мухи:
просмотр, оценка по пяти шкалам, статусы от бэклога до публикации, сравнение на радаре,
перенос идей между проектами.

Стек: Vite + React 19 + Tailwind v4 + shadcn/ui (new-york) + чарты в духе [Bklit](https://bklit.com) на recharts + Electron.

## Запуск на Windows (без консоли)

Нужен только [Node.js](https://nodejs.org) 22+ (LTS). Дальше:

| Файл | Что делает |
| --- | --- |
| `START.bat` | Двойной клик → открывается окно программы. При первом запуске сам докачает зависимости. |
| `BUILD-EXE.bat` | Собирает портативный `release\Fly-Ideas-0.1.0-win64.exe` — можно носить на флешке, установка не нужна. |

## Вручную (если хочется)

```powershell
cd fly-ideas
npm install
npm run electron:dev   # окно программы + горячая перезагрузка
npm run dev            # только в браузере, http://localhost:5173
npm run dist           # собрать .exe в release/
```

## Оформление

Внешний вид намеренно сдержанный: наборная вёрстка вместо витрины.

- палитра приглушённая: серо-коричневый, сталь, олива, охра, кирпич; отдельно тёмная и светлая темы, без чистого белого фона и фиолетового с чёрным;
- квадратные углы, волосяные линии, отсутствие теней, градиентов, размытия и скользящего стекла;
- подписи и числа моноширинные, цифры табличные, шапки разделов капслоком;
- ни одной пиктограммы: действия подписаны словами, состояния показаны квадратами и штриховкой;
- без анимаций: наведение и выбор меняют цвет мгновенно;
- интерфейс без всплывающих подсказок-украшений, счётчиков аналитики и заглушек-скелетонов.

## Данные: два коннектома, зачем оба

| Набор | Что это | Для чего в проекте |
| --- | --- | --- |
| **FlyWire v783** (самка, 139 тыс. нейронов) | женский мозг, аннотации типов клеток и предсказания нейромедиаторов 2024 года | основной: под него есть готовый код модели Shiu et al. и бенчмарки, на нём собраны почти все статьи по MB и обучению |
| **MaleCNS v1.0** (самец, 165 тыс. нейронов, около 12 тыс. типов клеток) | полная ЦНС самца: мозг, оптические доли и брюшная нервная цепочка с сохранённым шейным коннектором, релиз 2026 года, CC-BY 4.0 | для второго шага: пол и ухаживание, моторный выход вместо декодированного readout, сравнение полов |

MaleCNS скачивается во вкладке «Мозг» → «Данные и окружение»: аннотации (13 МБ) и предсказания нейромедиаторов (42 МБ). Крупные таблицы связности лежат в открытом бакете Google и берутся через neuPrint или инструменты Janelia: ссылки в разделе «внешние источники».

Готовой LIF-модели и бенчмарков на MaleCNS пока нет: перенос загрузчика fly-brain на мужские таблицы это отдельная методическая работа (идея «Память отвергнутого самца»).

## Ключи API

- **DeepSeek** (код): ключ с platform.deepseek.com, вставляется в панели помощника справа.
- **Perplexity** (поиск литературы): ключ с perplexity.ai/settings/api, там же.

Оба ключа лежат в файле `secrets.json` в папке данных приложения и передаются только в main-процесс: со стороны окна они недоступны. Запросы уходят на api.deepseek.com и api.perplexity.ai напрямую, без посредников.

## Правовое

В меню приложения два документа: «Условия использования» и «Политика конфиденциальности». Коротко: программа работает локально, телеметрию не собирает, ключ DeepSeek лежит в файле `secrets.json` папки данных приложения, в сеть уходят только запросы к api.deepseek.com (если вы сами пользуетесь помощником) и загрузка открытых файлов данных с github.com.

## Что внутри

- **Проект** — открывается щелчком по проекту в сайдбаре. Название и описание правятся прямо здесь, цвет переключается пятью образцами. Сверху строка состояния: сколько идей, сколько этапов пройдено, прогонов, источников, что доведено до подачи, ближайший срок. Дальше три вещи: описание проекта, пути рабочего места (папка кода и папка прогонов, кнопки «Показать прогоны» и смены папки) и таблица идей по приоритету. Ниже состояние по статусам, последние записи журнала и источники проекта. Главная кнопка — **«Начать проект»** (если работа ещё не начиналась) или **«Продолжить проект»**: она открывает рабочее место этого проекта, при первом входе создаются папки и копируются шаблоны.
- **Идеи** — плотная таблица: одна строка на идею (статус, оценки с сводным приоритетом, прогресс чеклиста, дедлайн, метки, счётчики источников и записей). Поиск, фильтр по статусу, сортировка по приоритету, влиянию, лёгкости, скорости или дате. Строку можно перетащить на проект. Клик открывает диалог с пятью вкладками:
  - **Разбор** — вопрос, метод, валидация, журналы, ссылки, заметки, оценки;
  - **Чеклист** — этапы «от идеи до статьи» (стандартный конвейер из 9 шагов, можно править, добавлять, перетаскивать; галочки хранят дату);
  - **Журнал** — лабораторный дневник: дата / что запускал / параметры (сид, бэкенд, коммит) / результат / вывод, исход «получилось / частично / нет / неясно», кнопка «повторить с теми же параметрами»;
  - **Источники** — статьи, привязанные к идее, с полем «зачем нужна здесь»; поиск по общей базе или создание нового источника на месте;
  - кнопка **«Черновик статьи»** в шапке идеи собирает markdown: вопрос, метод, валидация, таблица прогонов из журнала, оценки, незакрытые этапы, литература со ссылками и DOI. Черновик можно скопировать или сохранить файлом `.md`;
  - **Связи** — «растёт из…» (какие идеи нужно сделать раньше) и обратные связи.
- **Библиотека** — общая база источников на все проекты: автор, год, название, журнал, DOI/URL, теги, конспект. Видно, в каких идеях источник используется и зачем. Фильтр по тегам, «только текущий проект», копирование списка литературы в буфер. Быстрый разбор строки с DOI/годом.
- **Дашборд** — карта «трудоёмкость × влияние» (размер точки — новизна), воронка статусов, дерево идей (граф зависимостей), список дедлайнов с подсветкой «скоро / просрочено», последние записи журнала, счётчики.
- **Сравнение** — радар до трёх идей и таблица по всем полям: оценки, этапы, сроки, источники, метки, выходы. Отметка для сравнения ставится галочкой в строке таблицы.
- **Проекты** — сайдбар слева. Перенос идеи: перетащить строку на проект, меню «··· → Переместить в» или смена проекта в диалоге. Есть «Копировать в».
- **Мозг** (только в окне Electron) — рабочее место проекта. У каждого проекта своя папка кода и своя папка прогонов, обе можно переназначить (например, на большой диск), выбор запоминается:
  - **слева проводник**: файлы проекта `.py` (новый, импорт с диска, удаление, вернуть шаблоны) и прогоны со временем запуска, числом файлов и отметками «summary» и «графики»;
  - **в центре код и результаты**: редактор, поле аргументов, запуск и остановка; внизу появятся картинки, `summary.json`, прочие файлы и живой лог. Кнопка «в журнал идеи» переносит прогон в лабораторный дневник выбранной идеи;
  - **справа помощник**: DeepSeek для кода и Perplexity для литературы. Ответ с блоком Python сохраняется прямо в папку проекта, готовые файлы появляются слева. Строки с DOI из ответа Perplexity вносятся в библиотеку одной кнопкой. История переписки у каждого проекта своя;
  - **права помощника**: создавать файлы, перезаписывать существующие, разрешать запуск скриптов. Права проверяются в main-процессе, а не в интерфейсе;
  - **раздел «Данные и окружение»**: скачивание коннектома, проверка Python и пакетов, инструкции по установке;
  - кнопка «Как начать» открывает порядок работы из семи шагов и шаблон запроса к помощнику.

- **Данные** — хранятся локально (localStorage окна Electron). ⚙ → выгрузка/загрузка JSON через системный диалог выбора файла, сброс к стартовому набору. Список литературы из Библиотеки — в буфер или в файл.

## Папка workspace/

Создаётся рядом с программой при первом запуске (в git не попадает):

```
workspace/
  data/      скачанные данные коннектома
  scripts/   python-скрипты (шаблоны копируются из experiments/templates)
  runs/      результаты прогонов, по папке на запуск
```

Скрипт при запуске получает переменные окружения `FLY_DATA`, `FLY_RUN_DIR`, `FLY_SCRIPTS`.

Шаблоны в `experiments/templates/` (копируются в папку кода проекта кнопкой «Вернуть шаблоны»):

| файл | что делает |
| --- | --- |
| `00_check_env.py` | проверка Python, пакетов и доступа к данным |
| `01_load_connectome.py` | загрузка и разбор таблиц коннектома (FlyWire v783 или MaleCNS v1.0) |
| `02_mb_toy_interference.py` | игрушечная модель грибовидного тела: обучение, угасание, конкурент |
| `03_shiu_activate.py` | активация контура Shiu et al. и выгрузка спайков |
| `04_mb_sweep_heatmap.py` | развёртка по разреженности и числу мусорных ассоциаций, тепловая карта |
| `05_neuron_gallery.py` | галерея нейронов: морфология в трёх проекциях, наложение спайков, растр и gif с ходом сигнала |
| `06_brian2_shiu.py` | прогон LIF-модели Shiu et al. на Brian2: калибровка фона, стимуляция, `spikes.parquet` |
| `07_morph_activity_figure.py` | морфология MaleCNS и активность модели v783 в одной фигуре, с таблицей соответствия id |
| `08_malecns_loader.py` | загрузка связей и подписей MaleCNS v1.0, приведение к колонкам pre, post, weight |
| `09_mb_circuit_v783.py` | протокол обучения на реальных KC, MBON, PPL1: два компартмента, угасание, пассивная релаксация |
Любую из папок можно переназначить кнопкой «Выбрать…» — выбор запоминается в `config.json` в папке данных приложения (`%APPDATA%\fly-ideas`), кнопка ↺ возвращает умолчание.

## Окружение для прогонов

Скрипты моделей требуют пакетов, которых нет в системном Python. Окружение ставится один раз:

```powershell
conda env create -f environment.yml
conda activate fly-brain
```

Внутри `fly-brain` уже есть Brian2, NAVis, neuprint-python и cloud-volume. Для Brian2 нужен
`numpy<2`: в numpy 2 убрали `ndarray.ptp`, из-за чего импорт brian2 падает. Порядок прогонов
для новой идеи: `00` проверка окружения → `08` данные (для MaleCNS) или скачивание v783 во
вкладке «Мозг» → `06` прогон модели → `05`/`07` картинки → `09` протокол обучения.

## Bklit / shadcn

Проект заведён по [инструкции Bklit](https://bklit.com/docs/installation): `components.json` содержит реестр `@bklit`.
Базовые компоненты и чарты написаны вручную в том же стиле (Radix + recharts). Чтобы поставить оригиналы:

```powershell
npx shadcn@latest add button card badge dialog dropdown-menu select tabs input textarea label tooltip
npx shadcn@latest add @bklit/<имя-компонента>   # список: https://bklit.com/docs/components
```
