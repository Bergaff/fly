# Fly Ideas

Десктоп-программа (Windows 10+) для работы с идеями научных статей на модели мозга мухи:
просмотр, оценка по пяти шкалам, статусы от бэклога до публикации, сравнение на радаре,
перенос идей между проектами.

Стек: Vite + React 19 + Tailwind v4 + shadcn/ui (new-york) + чарты в духе [Bklit](https://bklit.com) на recharts + Electron.

## Запуск на Windows (без консоли)

Нужен только [Node.js](https://nodejs.org) 22+ (LTS). Дальше:

| Файл | Что делает |
| --- | --- |
| `START.bat` | Двойной клик: открывается окно программы. При первом запуске сам докачает зависимости. |
| `BUILD-EXE.bat` | Собирает портативный `release\Fly-Ideas-0.1.0-win64.exe`, можно носить на флешке без установки. |

## Вручную (если хочется)

```powershell
cd fly-ideas
npm install
npm run electron:dev   # окно программы + горячая перезагрузка
npm run dev            # только в браузере, http://localhost:5173
npm run dist           # собрать .exe в release/
```

## Оформление

Внешний вид намеренно сдержанный: наборная вёрстка вместо витрины.

- палитра приглушённая: серо-коричневый, сталь, олива, охра, кирпич; отдельно тёмная и светлая темы, без чистого белого фона и фиолетового с чёрным;
- квадратные углы, волосяные линии, отсутствие теней, градиентов, размытия и скользящего стекла;
- подписи и числа моноширинные, цифры табличные, шапки разделов капслоком;
- ни одной пиктограммы: действия подписаны словами, состояния показаны квадратами и штриховкой;
- без анимаций: наведение и выбор меняют цвет мгновенно;
- интерфейс без всплывающих подсказок-украшений, счётчиков аналитики и заглушек-скелетонов.

## Данные: два коннектома, зачем оба

| Набор | Что это | Для чего в проекте |
| --- | --- | --- |
| **FlyWire v783** (самка, 139 тыс. нейронов) | женский мозг, аннотации типов клеток и предсказания нейромедиаторов 2024 года | основной: под него есть готовый код модели Shiu et al. и бенчмарки, на нём собраны почти все статьи по MB и обучению |
| **MaleCNS v1.0** (самец, 165 тыс. нейронов, около 12 тыс. типов клеток) | полная ЦНС самца: мозг, оптические доли и брюшная нервная цепочка с сохранённым шейным коннектором, релиз 2026 года, CC-BY 4.0 | для второго шага: пол и ухаживание, моторный выход вместо декодированного readout, сравнение полов |

MaleCNS скачивается во вкладке «Мозг» → «Данные и окружение»: аннотации (13 МБ) и предсказания нейромедиаторов (42 МБ). Крупные таблицы связности лежат в открытом бакете Google и берутся через neuPrint или инструменты Janelia: ссылки в разделе «внешние источники».

Готовой LIF-модели и бенчмарков на MaleCNS пока нет: перенос загрузчика fly-brain на мужские таблицы это отдельная методическая работа (идея «Память отвергнутого самца»).

## Ключи API

- **DeepSeek** (код): ключ с platform.deepseek.com, вставляется в панели помощника справа.
- **Perplexity** (поиск литературы): ключ с perplexity.ai/settings/api, там же.

Оба ключа лежат в файле `secrets.json` в папке данных приложения и передаются только в main-процесс: со стороны окна они недоступны. Запросы уходят на api.deepseek.com и api.perplexity.ai напрямую, без посредников.

## Правовое

В меню приложения два документа: «Условия использования» и «Политика конфиденциальности». Коротко: программа работает локально, телеметрию не собирает, ключ DeepSeek лежит в файле `secrets.json` папки данных приложения, в сеть уходят только запросы к api.deepseek.com (если вы сами пользуетесь помощником) и загрузка открытых файлов данных с github.com.

## Что внутри

- **Проект** — открывается щелчком по проекту в сайдбаре. Название и описание правятся прямо здесь, цвет переключается пятью образцами. Сверху строка состояния: сколько идей, сколько этапов пройдено, прогонов, источников, что доведено до подачи, ближайший срок. Дальше три вещи: описание проекта, пути рабочего места (папка кода и папка прогонов, кнопки «Показать прогоны» и «Сменить папки», где каждая из двух папок переназначается или возвращается к значению по умолчанию) и таблица идей по приоритету. Ниже состояние по статусам, последние записи журнала и источники проекта. Главная кнопка — **«Начать проект»** (если работа ещё не начиналась) или **«Продолжить проект»**: она открывает рабочее место этого проекта, при первом входе создаются папки и копируются шаблоны.
- **Идеи** — плотная таблица: одна строка на идею (статус, оценки с сводным приоритетом, прогресс чеклиста, дедлайн, метки, счётчики источников и записей). Поиск, фильтр по статусу, сортировка по приоритету, влиянию, лёгкости, скорости или дате. Строку можно перетащить на проект. Клик открывает диалог с пятью вкладками:
  - **Разбор** — вопрос, метод, валидация, журналы, ссылки, заметки, оценки;
  - **Чеклист** — этапы «от идеи до статьи» (стандартный конвейер из 9 шагов, можно править, добавлять, перетаскивать; галочки хранят дату);
  - **Журнал** — лабораторный дневник: дата / что запускал / параметры (сид, бэкенд, коммит) / результат / вывод, исход «получилось / частично / нет / неясно», кнопка «повторить с теми же параметрами»;
  - **Источники** — статьи, привязанные к идее, с полем «зачем нужна здесь»; поиск по общей базе или создание нового источника на месте;
  - **внешний агент (MCP)**: мост к DeepSeek Harness, Claude Code или Codex. Агент видит идеи, журнал, литературу, данные и прогоны, запускает скрипты и пишет в журнал, а правки проходят через окно приложения с уведомлением. Включается в разделе «Данные и окружение».
  - кнопка **«Черновик статьи»** в шапке идеи собирает markdown: вопрос, метод, валидация, таблица прогонов из журнала, оценки, незакрытые этапы, литература со ссылками и DOI. Черновик можно скопировать или сохранить файлом `.md`;
  - **Связи** — «растёт из…» (какие идеи нужно сделать раньше) и обратные связи.
- **Библиотека** — общая база источников на все проекты: автор, год, название, журнал, DOI/URL, теги, конспект. Видно, в каких идеях источник используется и зачем. Фильтр по тегам, «только текущий проект», копирование списка литературы в буфер. Быстрый разбор строки с DOI/годом.
- **Дашборд** — карта «трудоёмкость × влияние» (размер точки — новизна), воронка статусов, дерево идей (граф зависимостей), список дедлайнов с подсветкой «скоро / просрочено», последние записи журнала, счётчики.
- **Сравнение** — радар до трёх идей и таблица по всем полям: оценки, этапы, сроки, источники, метки, выходы. Отметка для сравнения ставится галочкой в строке таблицы.
- **Проекты** — сайдбар слева. Перенос идеи: перетащить строку на проект, меню «··· → Переместить в» или смена проекта в диалоге. Есть «Копировать в».
- **Мозг** (только в окне Electron): рабочее место проекта и отдельных идей. Переключатель «идея» создаёт отдельные папки кода и прогонов для каждой исследовательской идеи, а список «идеи в мозге» позволяет открыть их напрямую; проекты остаются верхним уровнем группировки. Папки проекта или идеи можно переназначить (например, на большой диск), выбор запоминается:
  - **слева проводник**: файлы выбранной идеи `.py` (`шаблоны`, `новый`, `импорт`, удаление) и её прогоны со временем запуска, числом файлов и отметками `summary` и `графики`;
  - **в центре код и результаты**: редактор, поле аргументов, запуск и остановка; внизу появятся картинки, `summary.json`, таблицы `.csv` и живой лог. Кнопка «копировать лог» отправляет вывод в буфер обмена, а «в журнал идеи» переносит прогон в лабораторный дневник;
  - **справа вкладка «По задачам (без API)»**: готовый проверенный код анализа под все 10 текущих исследовательских задач (`10..19` и общий модуль `flylib.py`), чтобы запускать расчёты локально на ПК без платной генерации с нуля через DeepSeek API. В каждой задаче три готовых режима одной кнопкой (`--synth` для мгновенной проверки, прогон на локальных данных `FLY_DATA` и расширенный протокол); файлы появляются в пространстве выбранной идеи;
  - **справа вкладка «Помощник API»**: DeepSeek для доработки кода и Perplexity для литературы. Ответ с блоком Python сохраняется в папку выбранной идеи, история чата тоже разделена по идеям, строки с DOI из ответа Perplexity вносятся в библиотеку одной кнопкой;
  - **права помощника**: создавать файлы, перезаписывать существующие, разрешать запуск скриптов. Права проверяются в main-процессе, а не в интерфейсе;
  - **раздел «Данные и окружение»**: скачивание коннектома FlyWire v783, аннотаций Schlegel et al. 2024 и таблиц MaleCNS, проверка Python и пакетов, подключение внешнего агента MCP.

- **Данные** — хранятся локально (localStorage окна Electron). ⚙ → выгрузка/загрузка JSON через системный диалог выбора файла, сброс к стартовому набору. Список литературы из Библиотеки — в буфер или в файл.

## Папка workspace/

Создаётся рядом с программой при первом запуске (в git не попадает):

```
workspace/
  data/      скачанные данные коннектома
  scripts/   python-скрипты (шаблоны копируются из experiments/templates)
  runs/      результаты прогонов, по папке на запуск
```

Скрипт при запуске получает переменные окружения `FLY_DATA`, `FLY_RUN_DIR`, `FLY_SCRIPTS`.

Шаблоны и готовый код анализа задач в `experiments/templates/` (автоматически раскладываются в папку кода проекта и обновляются кнопкой `шаблоны`):

| файл | что делает |
| --- | --- |
| `flylib.py` | общий модуль загрузчиков FlyWire v783 / MaleCNS, синтетического коннектома, векторного LIF-ядра Shiu et al. 2024 и оформления графиков Bklit |
| `00_check_env.py` | проверка Python, пакетов и доступа к данным |
| `01_load_connectome.py` | загрузка и разбор таблиц коннектома (FlyWire v783 + аннотации типов клеток) |
| `02_mb_toy_interference.py` | игрушечная модель грибовидного тела: обучение, угасание, конкурент |
| `03_shiu_activate.py` | активация контура Shiu et al. и выгрузка спайков |
| `04_mb_sweep_heatmap.py` | развёртка по разреженности и числу мусорных ассоциаций, тепловая карта |
| `05_neuron_gallery.py` | галерея нейронов: морфология в трёх проекциях, наложение спайков, растр и gif с ходом сигнала |
| `06_brian2_shiu.py` | прогон LIF-модели Shiu et al. на Brian2: калибровка фона, стимуляция, `spikes.parquet` |
| `07_morph_activity_figure.py` | морфология MaleCNS и активность модели v783 в одной фигуре, с таблицей соответствия id |
| `08_malecns_loader.py` | загрузка связей и подписей MaleCNS, приведение к колонкам pre, post, weight |
| `09_mb_circuit_v783.py` | протокол обучения на реальных KC, MBON, PPL1: два компартмента, угасание, пассивная релаксация |
| `10_virtual_lesions.py` | задача `i-lesions`: виртуальные лезии нейропилей, кривая доза-эффект (0..100%) и матрица парного эпистаза |
| `11_mb_interference_connectome.py` | задача `i-interference`: ретроактивная интерференция в MB, 4 поведенческих теста возврата следа и проверка маскировки весов |
| `12_backend_benchmark.py` | задача `i-benchmark`: честный бенчмарк Brian2, разреженного SciPy/CSR, NumPy и PyTorch/CUDA на одних и тех же уравнениях LIF |
| `13_whole_brain_mb_learning.py` | задача `i-mb-learning`: 3-факторная пластичность KC->MBON и торможение APL внутри спайковой сети целого мозга |
| `14_malecns_courtship_memory.py` | задача `i-courtship-memory`: память при ухаживании на MaleCNS против самки v783, кривые Siegel & Hall 1979 (дикий тип vs amnesiac) |
| `15_memory_to_motor_vnc.py` | задача `i-memory-to-action`: передача следа памяти MB -> MBON -> шейные DN -> мотонейроны VNC, латентности и избыточность пула |
| `16_observational_learning.py` | задача `i-observational`: аудит путей зрение->DAN (1..3 шага), обучение наблюдателя O от демонстратора D, 4 контроля и цепочка D->O1..O4 |
| `17_individuality_phenotypes.py` | задача `i-individuality`: устойчивость индивидуальности между днями (чистый шум vs микро-вариация развития vs пластичность), ICC(1,1) и PCA |
| `18_courtship_song_ipi.py` | задача `i-song`: слуховой каскад JO->AMMC->WED->vPN1->pC1, настройка на IPI 35 мс и сравнение статичного LIF с STP и тормозной задержкой |
| `19_pci_integration.py` | задача `i-pci`: индекс пертурбационной сложности Лемпеля-Зива (PCI) и баланс интеграции/дифференциации против shuffled и решётки |

Любую из папок можно переназначить кнопкой «выбрать»: выбор запоминается в `config.json` в папке данных приложения (`%APPDATA%\fly-ideas`), кнопка «сбросить» возвращает умолчание.

## Внешний агент (MCP)

Приложение поднимает локальный мост, через который внешний агент (DeepSeek Harness, Claude Code,
Codex или любой MCP-хост) видит идеи, журнал, библиотеку, данные и прогоны, запускает скрипты
проекта и может писать в журнал. Мост слушает только `127.0.0.1`, порт выбирается случайно, каждый
запрос требует токен. Токен и порт лежат в `agent.json` в папке данных приложения
(`%APPDATA%\fly-ideas`). Выключатель: вкладка «Мозг», раздел «Данные и окружение»,
блок «Подключение агента».

Что умеет агент:

| Инструмент | Что делает |
| --- | --- |
| `fly_status` | проекты, права, папки, число идей и прогонов |
| `fly_list_ideas`, `fly_get_idea` | идеи кратко и целиком: вопрос, метод, чеклист, журнал, источники |
| `fly_search_library`, `fly_add_reference` | библиотека источников, DOI |
| `fly_list_scripts`, `fly_read_script` | файлы кода проекта |
| `fly_run_script`, `fly_wait_run`, `fly_kill_run` | запуск прогона и разбор итога (summary, лог) |
| `fly_list_runs`, `fly_read_run` | история прогонов |
| `fly_list_data` | что скачано в папку данных |
| `fly_add_journal_entry` | запись в лабораторный журнал идеи |
| `fly_add_idea`, `fly_update_idea` | новая идея и правка полей |

Записи агента применяются только через окно приложения: оно показывает уведомление и сохраняет
изменение в своё состояние, поэтому ничего не пишется в обход интерфейса. Права на файлы
проверяются в main-процессе, как и для помощника внутри приложения.

Подключение в DeepSeek Harness: добавь плагин MCP-клиента в `cordis.patch.yml` профиля (точную
схему сверь с документацией dsh, она ещё меняется в превью):

```yaml
- name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: fly
    transport: stdio
    command: node
    args: ['C:/путь/к/Fly Ideas/resources/mcp/server.mjs']
```

Для Claude Code: `claude mcp add fly -- node "C:/путь/к/Fly Ideas/resources/mcp/server.mjs"`.
Готовые строки с настоящими путями показывает блок «Подключение агента» в приложении,
их можно скопировать кнопкой.

## Окружение для прогонов

Скрипты моделей требуют пакетов, которых может не быть в системном Python. Для обычной установки открой в программе «Мозг» → «Данные и окружение» и нажми «установить недостающие пакеты». Приложение создаст отдельное окружение `workspace/.venv`, установит `pandas`, `numpy`, `scipy`, `matplotlib`, `pyarrow` и автоматически будет запускать скрипты через него. Системный Python не изменяется. Для установки без интерфейса можно дважды щёлкнуть `SETUP-PYTHON.bat`.

Полное окружение conda (`environment.yml`) дополнительно содержит Brian2, NAVis, neuprint-python и cloud-volume. Для совместимости Brian2 и таблиц parquet зафиксированы `numpy<2` и `pyarrow<19` на Python 3.11/3.12: в numpy 2 убрали `ndarray.ptp`, а pyarrow 20+ требует numpy 2. Порядок работы без API: открой вкладку «Мозг», выбери идею в списке «идеи в мозге», справа открой нужную задачу во вкладке «По задачам (без API)», запусти быстрый прогон `--synth`, затем скачай данные в «Данные и окружение» и запусти полный режим на `FLY_DATA`.

## Bklit / shadcn

Проект заведён по [инструкции Bklit](https://bklit.com/docs/installation): `components.json` содержит реестр `@bklit`.
Базовые компоненты и чарты написаны вручную в том же стиле (Radix + recharts). Чтобы поставить оригиналы:

```powershell
npx shadcn@latest add button card badge dialog dropdown-menu select tabs input textarea label tooltip
npx shadcn@latest add @bklit/<имя-компонента>   # список: https://bklit.com/docs/components
```
