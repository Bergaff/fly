# Публичная страница результатов на GitHub Pages

## Что публикуется

Workflow `.github/workflows/pages.yml` собирает отдельный public mode приложения. В нём нет локальных путей, Electron-моста, пользовательских папок и функций запуска Python. Публикуются:

- визуальный итог roadmap82–90;
- проверенные метрики frozen89E;
- итог mapping gate series90;
- интерактивный двухмушиный демонстратор;
- ограничения биологической интерпретации;
- ссылка на воспроизводимые отчёты репозитория.

Введённая посетителем последовательность остаётся в браузере и не отправляется на сервер.

## Как включить Pages без командной строки

1. Откройте репозиторий GitHub.
2. Перейдите в `Settings` → `Pages`.
3. В разделе `Build and deployment` выберите источник `GitHub Actions`.
4. Откройте вкладку `Actions`.
5. Выберите `Deploy research showcase to GitHub Pages`.
6. Нажмите `Run workflow` и выберите ветку с подготовленными файлами. После merge следует выбирать `main`.
7. После зелёного завершения адрес страницы появится в шаге `Deploy` и в `Settings` → `Pages`.

Workflow также автоматически пересобирает страницу при изменении public source на закреплённой рабочей ветке или `main`.

## Что делает интерактивный демонстратор

Посетитель составляет последовательность из шести блоков по0,6 секунды:

- потирание передних лап;
- движение лап к голове;
- вытягивание и убирание лап;
- пауза.

Для каждого блока задаётся амплитуда. После показа есть задержка0,5 секунды, затем вторая муха визуально повторяет последовательность.

Это deterministic browser surrogate на основе трёх action families, проверявшихся в сериях86–89E. Он нужен для объяснения принципа и не запускает frozen Python policy89E. Значения более100% прямо считаются выходом за проверенную область. Demo fidelity не является научной метрикой.

## Почему нельзя честно запускать exact89E в Pages

GitHub Pages является статическим хостингом. Exact89E использует Python runner, frozen model artifacts, synthetic visual pipeline и trial simulation, которые не входят в браузерный build. Кроме того, committed extract содержит метрики trials, но не все веса и trajectory data, необходимые для exact arbitrary-motion inference.

Поэтому страница не выдаёт browser-анимацию за новый расчёт. Exact результат представлен только сохранёнными отчётами и проверенными агрегатами. Если позже будет подготовлен отдельно аутентифицированный browser inference bundle с frozen weights, его нужно валидировать против Python runner до замены surrogate.

## Локальная проверка разработчиком

Public build использует переменную `VITE_PUBLIC_SHOWCASE=1`. GitHub Actions устанавливает её автоматически; посетителю и владельцу Pages ничего вводить не нужно.
