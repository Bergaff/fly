# Серия 66: пользовательский результат полного автономного пути

Статус: завершено по вставленным пользователем `ОТЧЕТ.txt` и `summary.json`. Оригинальные файлы не получены, поэтому их собственные байты и полный манифест результата независимо не проверены. Компактная точная транскрипция находится в `observe-delay-autonomous-replay-user-summary-extract.json`; её арифметика проверяется отдельной fixture.

## Зафиксированный результат

- Обучающих эпизодов: 60 094.
- Пять заранее закреплённых holdout, по 51 кадру, с разными source SHA и motion SHA.
- Состояние: 72 коэффициента после полного наблюдения; задержка 0,5 с без обновлений.
- Replay использовал только состояние и временную фазу.
- Средняя RMSE normal: 0,3866169501 рад.
- Средняя RMSE stationary zero: 0,3642577771 рад.
- Primary, normal минус zero: **+0,0223591730 рад**, то есть normal хуже. Относительно средней RMSE нуля разность составляет примерно +6,14%.
- Normal лучше zero только на 1 из 5 движений. Парные разности: +0,035516; −0,003927; +0,023851; +0,010099; +0,046256 рад.

Основной заранее заданный критерий не пройден. Полный программный путь от наблюдения через сохранённое состояние и задержку до автономно созданных шести углов технически выполнен, но это состояние не обеспечило полезное обобщение на батарее новых случайных движений.

## Контроли

Средняя RMSE:

| Условие | RMSE, рад | Разность с normal, рад |
|---|---:|---:|
| normal | 0,386617 | 0 |
| static first frame | 0,385704 | −0,000912 |
| shuffled | 0,391374 | +0,004757 |
| reversed | 0,397539 | +0,010922 |
| closed | 0,424903 | +0,038286 |

Closed хуже normal примерно на 0,0383 рад, а reversed также хуже: изображения несут некоторую информацию. Однако static чуть лучше normal, shuffled близок, а normal выигрывает у static только на 2/5 holdout. Поэтому результат не показывает, что модель надёжно использует правильную временную структуру наблюдаемого движения. Вероятнее, значительная часть доступного сигнала связана с общей внешностью или распределением яркости, а temporal encoding недостаточен.

## Разбор по осям

Поскольку во всех holdout одинаково 51 кадр, из пяти осевых RMSE можно восстановить объединённую осевую RMSE:

|---|---:|---:|---:|
| left_x | 0,444950 | 0,381232 | +16,71% |
| left_y | 0,310525 | 0,358358 | −13,35% |
| left_z | 0,432286 | 0,388285 | +11,33% |
| right_x | 0,384613 | 0,309870 | +24,12% |
| right_y | 0,306372 | 0,325393 | −5,85% |
| right_z | 0,419896 | 0,417835 | +0,49% |

Состояние помогает для `left_y` и `right_y`, почти нейтрально для `right_z`, но заметно ухудшает `left_x`, `left_z` и особенно `right_x`. Это не один локальный дефект: отказ распределён по нескольким осям.

## Интерпретация и следующий метод

Пять holdout созданы новым генератором как кусочно-линейные случайные движения с изменением шести углов каждые 0,5 с. Обучающий набор серии 59 имеет другое, более структурированное распределение движений. Поэтому наблюдается сильный и заранее не устранённый distribution shift. Это объяснение правдоподобно, но не доказано одним набором из пяти движений.

Следующую модель нельзя подбирать по этим пяти holdout и нельзя включать их в обучение. Рациональный следующий этап:

1. оставить эти пять движений закрытой использованной батареей;
2. до расчёта создать новую независимую батарею;
3. обучать на независимо сгенерированных кусочно-линейных траекториях того же общего класса, но с другими seed и без пяти пользовательских файлов;
4. увеличить наблюдаемое представление и отдельно проверить temporal information: прямые блоки яркости или существенно больше observer features вместо 24 случайных проекций;
5. сравнивать normal не только с zero, но и с static/shuffled/reversed, требуя заранее заданного преимущества normal;
6. не менять одновременно слишком много компонентов без диагностического ablation.

## Ограничения

Это supervised episode-level ridge и cosine decoder, не моторная система мухи. Observer units искусственные. Пять файлов не являются независимыми животными. Противоположные знаки у zero не определены содержательно, поэтому счётчики `opposite_sign_values` normal нельзя напрямую сравнивать с нулевым контролем. Результат не доказывает наличие или отсутствие зеркальных нейронов.
