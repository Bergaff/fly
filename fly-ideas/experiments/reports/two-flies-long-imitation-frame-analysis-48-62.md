# Покадровый анализ последовательностей 48 и 62

Пользователь прикрепил файл `predictions.csv`, размер 603 205 байт, SHA-256 `aafc0f5bd54df465a54b30748635022774af1156c697d04cf4982ba537b5ce57`, вычисленный здесь по присланному файлу. Проверены 3072 строки, 64 последовательности по 48 кадров (2–49), времена `frame/25`, постоянство условий внутри каждой последовательности, нулевой прогноз, ограничение выходов ±0,65 рад и правильность `clip_floor`. Пересчитанные общие RMSE новой / старой / нуля / clip-floor **0,155050330 / 0,214168502 / 0,362799265 / 0,014977885 рад** и MAE совпадают с присланными ранее метаданными. Также проверено совпадение параметров и RMSE каждой из 64 последовательностей с ранее вручную выписанными и округлёнными строками таблицы.

При этой сверке найдена и исправлена ошибка прежней ручной выписки: фаза ID 36 была записана 106,947357 вместо округлённого из файла значения 106,947356 градуса. Остальные выписанные значения совпали в пределах округления. Суммарные RMSE, разбиения по формам и ранее представленные выводы от этой поправки не изменились. Сверка метрик не проверяет исходные модели, изображения, SQLite или сами хэши этих файлов. Здесь не храним целиком пользовательский файл: для воспроизведения разборов отдельно сохранена выписка 96 строк `two-flies-long-imitation-user-frames-48-62-rounded.csv`, значения округлены до шести знаков, файл не является оригиналом.

**Определение ошибки:** `предсказанный угол − угол учителя`. Отрицательная ошибка означает, что предсказанный угол алгебраически меньше эталона; это не обязательно означает меньший абсолютный угол. Оба движения асимметричные; параметры установлены после просмотра результатов, набор уже использовался в локальном пилоте. Это исследовательский разбор, не слепое подтверждение.

Во всех 11 и 13 несовпадениях знака новой модели эталонный угол положительный, а предсказанный отрицательный. Кадры зависимы, и для углов около нуля знак чувствителен даже к малым ошибкам. Отрицательная средняя ошибка не объясняет механизм, но показывает для этих сцен большой систематический сдвиг на фоне движения. Высокая корреляция не отменяет этот сдвиг: постоянное смещение не меняет корреляцию, но увеличивает RMSE.

Старая модель на этих двух сценах часто упирается в **−0,65 рад**; выход новой ограничивается лишь один раз в ID 62. При этом все эталонные углы в обоих показах лежат примерно в диапазоне ±0,35 рад, `clip_floor` равен нулю. Само ограничение не вынуждает здесь ошибку относительно эталона, хотя ограничение *предсказанного выхода* явно срабатывает у старой модели. Установить, из-за чего вход изображения и веса дают этот сдвиг и насыщение, по одним предсказаниям нельзя.

По абсолютной покадровой ошибке новая модель лучше нуля в 25 из 48 кадров ID 48 и 17 из 48 кадров ID 62; однако её RMSE на обоих показах хуже нуля, потому что RMSE учитывает величины ошибок в квадрате, а не только число выигранных кадров. Новой модели ближе эталон, чем старой, во всех 48 кадрах ID 48 и в 47 из 48 кадров ID 62.

Описательное разложение RMSE² = квадрат средней ошибки + средний квадрат отклонений ошибки от её среднего: квадрат смещения составляет около 83,5% RMSE² новой модели для ID 48 и 81,1% для ID 62. Если математически вычесть среднюю ошибку **из тех же проверочных кадров**, оставшееся среднеквадратичное отклонение было бы 0,100367 и 0,140789 рад соответственно. Это демонстрация вклада смещения, **не результат доступного предсказателя**: значение поправки вычислено с истинными углами этих проверочных показов. Нельзя подправить выход на их основе и затем представлять оценку на тех же показах как независимую.

## Что проверять дальше

Оба случая имеют положительное смещение чуть больше +0,6, а дистанция ID 62 немного ниже 3,4. Это наблюдение получено после просмотра; такие же сдвиги не доказаны для других фаз, расстояний, форм или смещений. Можно заранее зафиксировать парный план с замороженными весами: отдельно варьировать смещение вокруг +0,6 и расстояние вокруг 3,4, удерживая остальные параметры, добавив отрицательные смещения, несколько амплитуд и форм. Важно отдельно проверять систематический сдвиг, знак, насыщение и RMSE против нуля, не корректируя модель по оценочному набору. Если позже понадобится калибровка, её обучать на отдельном калибровочном наборе и оценивать ещё на другом. Новая синтетическая проверка не является независимым биологическим повтором.

Данные показывают поведение линейного readout, обученного по эталонным углам и работающего во время показа. Они не показывают LIF-активность второй мухи, автономное воспроизведение действия или зеркальные нейроны.
