# Шесть осей: локальная техническая проба

Это короткая проверка новой реализации, а не 4–8-часовая серия и не пользовательский результат. Исходная траектория: `experiments/examples/wing-studio-local-pilot.json`, SHA-256 `83197964ce7edde6128d9a01dac79190abba68b1f42d6b9ebf69ad1da142052e`. У неё три ключевых кадра на 0, 1 и 2 с; в середине заданы углы `[30, 10, 20, -25, 5, -10]` градусов по порядку левое X/Y/Z, правое X/Y/Z. Это не движение из старой серии и не универсальный набор движений.

Скрипт `50_two_flies_wing_studio_pilot.py`, SHA-256 `768b3c6b940e803b120340012c069794c7bb7292dcd81c0db0f81fca987ac6ed`; Python 3.11.2, NumPy 1.26.4, MuJoCo 3.3.7, Brian2 2.9.0, Pillow 11.3.0. Использованы 48 синтетических обучающих и 8 отдельных синтетических проверочных последовательностей, seed 20261108. Дополнительно проверена указанная траектория, не входившая в обучение. Форма восьми проверочных движений кусочно-линейная, обучающих синусоидальная. Моделируется упрощённая кинематическая сцена, положение и ракурс не варьируются.

По двум осям примерной траектории модель хуже неподвижного контроля, хотя общая ошибка ниже. Проверочные данные и код наблюдались при разработке, слепой оценки нет. Нельзя делать вывод об обучении любым движениям или биологическом зрении. Повтор использует запись прогнозов, не самостоятельную генерацию. GIF глаз представляет сохранённые кадры с уменьшенным цветовым разрешением, точные RGB хранятся в NPZ. В этот запуск другие системные тесты выполнялись параллельно, время работы не является ориентиром для Windows. Полная проверка GUI/WebGL и BAT на Windows не выполнялась.
