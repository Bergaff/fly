# Обучение на пользовательском формате траекторий: локальная техническая проба

Результат разработчика, не пользовательский расчёт. В локальной Linux-среде Python 3.11.2, NumPy 1.26.4, MuJoCo 3.3.7, Brian2 2.9.0, Pillow 11.3.0 выполнен скрипт `51_two_flies_user_trajectory_learning.py`, SHA-256 `2c7e99c9d8f2b3b5a2d33ab119acf78b11b39cd4b079ac564747c62c5f86e5c6`. Использованы три небольших JSON из `experiments/examples/wing-user-training/`: два для обучения, один для проверки. Это примеры, созданные разработчиком в формате редактора, не движения пользователя. Проверочный файл не использовался при подгонке весов.

Программа сообщила 98 обучающих и 49 проверочных кадров (первые два кадра каждого движения идут в историю). На тестовом движении RMSE модель / нулевой угол / постоянный средний угол обучения составили `0,012815 / 0,172854 / 0,090051` рад. Эти три примера искусственно очень похожи по форме и отличаются главным образом амплитудой, а план и результат уже просмотрены. Это **не независимое подтверждение способности обобщать разнообразные пользовательские движения**. На других движениях модель может оказаться хуже обоих контролей. Длительность на Windows и работа в Word не проверялись.

Автоматическая фикстура `tests/user-wing-learning-fixture.py` проверяет: отказ при одинаковых последовательностях в обучении и проверке, включая добавление лишнего коллинеарного кадра; неизменность исходных файлов; соответствие накопленных статистик прямому ridge; неизменность весов при смене проверочной траектории; изменение весов при смене обучающей; согласованность сохранённых кадров глаз, входных признаков, модели и предсказаний. Тест не заменяет настоящий запуск BAT на Windows и не делает проверку слепой.

Новые результаты всегда сохраняются в отдельной папке. Это короткий однопроцессный пилот без возобновления, не запрошенная длительная серия на 4–8 часов. Выходы после показа являются сохранённым буфером предсказаний, а не автономным поведением. Подробнее о глазах: [observer-vision-explanation.md](observer-vision-explanation.md).
