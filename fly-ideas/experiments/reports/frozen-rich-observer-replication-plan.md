# Серия 68: независимая репликация замороженной модели 67

## Цель

Проверить положительный результат серии 67 без повторного обучения и без настройки по движениям 31–35. Это подтверждающая репликация в том же matched synthetic классе, а не расширение области обобщения.

## До оценки

Пользователь создаёт ровно пять новых JSON кнопкой «Случайное движение, шаг 0,5 с» при длительности 2 секунды. Runner принимает только ключевые точки 0 / 0,5 / 1 / 1,5 / 2 с. До первого прогноза файлы копируются, получают SHA и проверяются против:

- train/test серии 59;
- holdout серий 63–64;
- батареи 21–25 серии 66;
- батареи 31–35 серии 67;
- остальных файлов новой пятёрки.

## Замороженный источник

Источник должен быть полным успешным результатом серии 67:

- 60 000 эпизодов;
- `primary_pass = true`;
- завершённая SQLite stage;
- корректный `complete.json`;
- SHA модели совпадает с `summary.json`;
- weights имеют форму `1921 × 72`, projection побайтово совпадает с закреплённым seed 6701.

Модель, optimizer и source database открываются только для чтения. Нового Adam training нет.

## Оценка

На каждом новом движении замороженная модель формирует 72 коэффициента состояния из 1 920 level+delta признаков. После задержки 0,5 с replay получает только состояние и фазу.

Повторяются условия normal, stationary zero, static, deterministic shuffled, reversed и closed. Составной primary совпадает с серией 67: средняя RMSE normal должна быть ниже zero, static, shuffled и reversed. Дополнительно публикуется число движений, на которых normal отдельно лучше всех четырёх primary-контролей.

## Выходы

Для каждого holdout сохраняются observer activity, internal state, autonomous predictions, playback и metrics. Общий результат содержит `summary.json`, `ОТЧЕТ.txt`, protocol и SHA manifest. Незавершённая папка остаётся с `INCOMPLETE.txt` и не считается результатом.

## Ограничения

Репликация подтверждает только matched synthetic класс и не разделяет вклад matched training и rich encoder. Пять траекторий не являются животными. Искусственные observer units и cosine decoder не моделируют мозг, мышцы или аэродинамику и не доказывают зеркальные нейроны.
