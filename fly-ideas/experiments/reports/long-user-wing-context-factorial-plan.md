# Серия 62: полный факторный расчёт контекста `right_x`

## Зачем нужен новый расчёт

Серия 61 показала крупное улучшение при одновременном обнулении пяти контекстных осей, но одиночные сдвиги ±10° не позволяют разделить индивидуальные эффекты и взаимодействия. Серия 62 не обучает модель заново. Она проверяет все `2⁵ = 32` подмножества обнуления `left_x`, `left_y`, `left_z`, `right_y`, `right_z` при строго неизменном `right_x`.

Такой полный факторный план включает baseline, пять одиночных обнулений, все пары, тройки, четвёрки и `only_right_x`. Поэтому результат не зависит от одного выбранного порядка добавления осей. Для каждой замороженной модели рассчитывается точное Shapley-разложение:

- уменьшения суммы квадратов ошибки `right_x`;
- среднего сдвига прогноза относительно baseline.

Сумма пяти Shapley-вкладов обязана точно совпадать с полным эффектом `baseline → only_right_x`. Это математическое распределение эффекта в выбранной игре обнуления, а не доказательство биологической причинности.

## Две области оценки

1. Все 49 кадров `0,08–2,00` с. Это защищает от вывода только по проблемному участку.
2. Ранее локализованный участок `1,44–1,60` с. Он остаётся post hoc механистической диагностикой.

Для каждого из 32 условий сохраняются RMSE, MAE, SSE, средний прогноз, изменение относительно baseline и число кадров с противоположным знаком. Скрипт сначала обязан воспроизвести сохранённый baseline серии 59 с допуском `10⁻¹²` рад, иначе расчёт прекращается.

## Запуск

После обновления проекта дважды щёлкнуть:

`experiments\RUN-WING-CONTEXT-FACTORIAL.bat`

Выбрать завершённую папку `wing_user_long_...` и `new_test`, вероятно номер 2. Расчёт использует одну сцену и две замороженные модели, не повторяет восемь часов обучения и не изменяет серию 59. Он дольше серии 61, поскольку перерендеривает 32 условия.

Результат создаётся отдельно:

`workspace\runs\ideas\i-observational\wing-context-factorial\wing_factorial_...`

Нужно прислать текст `ОТЧЕТ.txt`. `summary.json` полезен для точной проверки, но NPZ не требуется. Полные таблицы сохраняются в `condition_metrics.csv` и `predictions.csv`.

Запасной запуск:

```powershell
workspace\.venv-two-flies\Scripts\python.exe experiments\templates\62_long_wing_context_factorial.py --series "ПУТЬ\wing_user_long_..." --test-id 2
```

## Ограничения

Обнулённые сочетания могут находиться вне обучающего распределения и менять видимость/перекрытие крыльев. Shapley-вклад зависит от конкретного набора пяти осей, baseline, операции обнуления, условных камер и выбранной метрики. Участок и `right_x` выбраны после просмотра серии 59. Это диагностика supervised ridge на искусственной сцене, не доказательство зеркальных нейронов, реального мозга, биологической причинности или автономного воспроизведения.
