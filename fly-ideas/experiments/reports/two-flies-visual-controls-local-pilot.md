# Зрительные контроли: локальный пилот

Технический запуск новой серии 41 на Linux, Python 3.11.2, NumPy 1.26.4, MuJoCo 3.3.7, Brian2 2.9.0 и Pillow 11.3.0. Длительность 2 секунды, 50 FPS, seed 0, 32 условных нейрона. Это результаты локального теста, не результаты Windows-пользователя.

| Условие | Всего спайков | Средняя абсолютная разность яркости |
|---|---:|---:|
| неподвижные крылья | 800 | 0 |
| неподвижный объект | 800 | 0 |
| крылья, 2 Гц, 0° | 1392 | 0,007075 |
| крылья, 3 Гц, 0° | 1458 | 0,008046 |
| крылья, 3 Гц, 90° | 1478 | 0,008268 |
| крылья, 4 Гц, 0° | 1507 | 0,008636 |
| объект, 3 Гц, 0° | 1516 | 0,011184 |

Например, ID 22 дал 79 спайков на крылья при 3 Гц и 111 на объект при 3 Гц; средняя разность его участка 0,0228 и 0,0496 соответственно. Разные результаты не означают избирательность, потому что стимулы не уравнены по геометрии или локальной яркостной динамике. Значения округлены. Кадры обновлялись 50 раз в секунду: это иной протокол, чем исходный запуск при 20 FPS, результаты нельзя считать независимым повтором одного и того же протокола.

Объект и крылья имеют разные форму, положение и траектории; фиксированное начальное состояние, смена стартовой фазы и транзиенты также влияют на ответ. Оценок неопределённости и независимых животных нет. Модель не проверяет зеркальные нейроны. Для собственного результата пользователь может запустить `experiments/RUN-TWO-FLIES-VISUAL-CONTROLS.bat`.
