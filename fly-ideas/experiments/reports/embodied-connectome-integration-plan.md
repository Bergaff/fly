# Серия 70: видимая и биологически ограниченная цифровая цепь

## Цель

Поэтапно соединить существующий результат серии 69 с официальными FlyVis, моделью Shiu и FlyGym, не скрывая искусственные адаптеры. Целевая цепь: две камеры второй мухи → FlyVis → закреплённое сопоставление типов с FlyWire ID → Shiu LIF → заранее заданный motor readout → FlyGym/MuJoCo.

## Реализовано сейчас

1. В Fly Ideas добавлен read-only демонстратор серии 69. Он открывает `result/holdout_001`, синхронно показывает наблюдение, 96 level и 96 delta activations, 24 compact units, задержку без обновлений, 72 коэффициента состояния и autonomous replay compact/rich. Это визуализация существующих файлов, не новый результат.
2. В «Данные и окружение» добавлена установка FlyVis 1.2.0, официальных pretrained-моделей и FlyGym 2.1.1. Она использует найденный Python 3.12, создаёт две изолированные среды и показывает потоковый журнал. Среда Shiu не изменяется; BAT установки только открывает интерфейс.
3. Добавлен preflight серии 70. Он проверяет три runtime, закреплённый авторский `model.py`, выбранные v630 tables и явно показывает два научных блокера.
4. Добавлена bounded fixture контрактов: visual activity → ID mapping → digital lesion → six body commands. В ней искусственные данные, `scientific_result=false`.

## Почему полный прогон пока заблокирован

Нельзя автоматически угадать соответствие выходных типов pretrained FlyVis конкретным FlyWire v630 ID. Также нельзя после просмотра результатов выбрать descending neurons и коэффициенты преобразования в шесть углов. Оба файла должны быть отдельно проверены и preregistered. Иначе эффект будет внесён адаптером, а не найден в модели.

## Следующие реализации

### 2. FlyVis

Получить точные два потока retinal frames из FlyGym, выполнить официальный pretrained FlyVis и сохранить activity по типам и времени. Сначала один bounded stimulus, затем батарея. Проверить версии, диапазоны, FPS и воспроизводимость.

### 3. Shiu

Создать versioned `flyvis-to-flywire-v630.json`: источник каждого типа, список FlyWire ID, правило перевода activity в rate, знак и допустимый диапазон. До результатов закрепить выходные популяции и лезии. Выполнить normal, shuffled, zero-state и lesion при одинаковом input stream.

### 4. FlyGym

Заранее определить readout: какие выходные популяции управляют какими командами. Сначала выводить команды рядом с кинематическим replay, затем передавать их актуаторам FlyGym. Сравнивать connectome, shuffled-connectome/readout и простой baseline на одном теле.

## Видимый итог

Демонстратор должен различать четыре происхождения сигнала: measured/connectome, pretrained, trained adapter и hand-defined control. Видео показывает первую муху, два retinal input, активность, задержку, вторую муху, normal и lesion/control. Светящаяся 3D-геометрия мозга допустима только для реально симулированных FlyWire ID; нынешние 96 units подписываются как искусственные.

## Ограничения

Даже полная цифровая цепь является вычислительной гипотезой, а не доказательством механизма живой мухи. Успех определяется заранее заданными метриками и контролями, не внешней убедительностью ролика.
